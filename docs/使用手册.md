# 雨落校园 V4.3 使用手册

## 作品主题与创意来源

《雨落校园》是一款以大学校园雨天通行为主题的规划小游戏。创意来自教学楼、图书馆、食堂与宿舍之间的日常出行场景，将雨天积水、校园绿化和入口遮雨转化为可操作的建设选择。

玩家使用有限预算安排树木、绿化、排水口和遮雨棚，再观察五轮天气中的安全度与舒适度变化。作品通过建设、观察和调整，让玩家比较不同校园环境改善方案的效果。

地图采用校园主题的随机示意布局。五栋建筑分别显示为骋望楼、东区主教、食堂、地下超市和西四，建筑位置随本局地图生成。

## 功能模块

| 模块 | 功能 |
|---|---|
| 校园地图 | 生成32×18逻辑格、20格道路、五栋建筑及8组建设位 |
| 设施规划 | 支持对称成组建设、费用预览、冲突提示、撤销、清空及建筑入口遮雨棚 |
| 天气与积水 | 播放昼夜和降雨效果，根据设施配置逐步计算道路积水 |
| 五轮结算 | 连续计算五轮天气，汇总事故、安全度、舒适度和综合分 |
| 方案优化 | 保留当前地图和天气序列重新调整设施，便于比较方案 |

路灯、长椅、花坛、人行道及背景草纹属于自动校园装饰。玩家可以购买的设施以建设工具栏为准，自动装饰不参与预算、积水或评分计算。

## 运行环境与启动

运行环境为 Windows x64，推荐1366×768或更大窗口。独立程序已包含所需运行环境。

1. 将整个“作品运行版”文件夹复制或解压到本地目录。
2. 打开该文件夹，双击“雨落校园.exe”。
3. 等待校园地图和右侧建设工具显示后开始操作。

运行电脑无需另行安装 Node.js、Python 或浏览器。请保留程序旁的 resources、locales、DLL和其他配套文件。程序通过本机回环地址读取随包资源，游戏使用本地素材和计算。

## 建设操作

每局初始预算为30。选择工具后，将鼠标移到地图带编号的候选地块，查看整组预览与费用，点击该组任一候选格即可建设。右侧点位1—8提供相同操作的辅助入口。

一组包含1或2个合法格，费用按实际新增实体数量计算。同类设施不重复购买，不同类型占位冲突或整组预算不足时拒绝建设。绿色表示可建，红色表示拒绝，灰色表示已建或无需新增。

选择遮雨棚后点击建筑，或使用右侧建筑列表安装。每栋建筑最多安装一座。树木、绿化和建筑提供多种外观，同类效果一致。

“撤销上一步”回退最近一次成功操作。“清空建设”清除设施并恢复30点预算。开始挑战后，本局建设锁定。

| 设施 | 每个单价 | 作用 |
|---|---:|---|
| 树木 | 2 | 每棵舒适度增加5，小雨时给予有限安全加分，暴雨事故可能带来额外扣分 |
| 草坪／草丛／矮灌木 | 1 | 每块舒适度增加2，邻近道路每步吸水0.5，暴雨事故可能额外扣分 |
| 排水口 | 3 | 邻近道路每步排水最多4，同类覆盖不叠加 |
| 遮雨棚 | 4 | 降低对应建筑入口的雨量和事故概率，舒适度增加1 |

## 五轮挑战与结果

点击“开始五轮挑战”后，连续播放5轮，每轮8步。每轮水量从零开始，设施保持。白天出现晴天或小雨，夜间出现无雨或暴雨，道路水面随计算步骤变化，达到积水阈值后才可能触发道路积水事故。

可以等待动画播放，也可点击“跳过动画并结算”。两者使用同一份预计算结果。结算显示评级、总分、平均安全度、舒适度和每轮事件。综合分由55%安全度和45%舒适度组成，预算余额不直接加分。

点击“优化当前方案”保留本局地图和天气序列，再调整设施进行比较。“全新挑战”生成新的地图与天气序列。复现信息位于顶栏折叠区。

## 窗口与常见问题

地图随窗口适配，右侧内容较多时可独立滚动。拥挤地图中的部分建筑使用小规格楼体，完整名称通过牌匾和建筑列表展示。

若复制后无法启动，先确认整个运行版目录已复制或解压完整。若界面拥挤，放大程序窗口或滚动右侧面板。

## 源码查看与开发运行

下载或克隆本仓库后，在含 package.json 的根目录打开终端。开发验证使用 Node.js 24与npm 11，首次安装开发依赖需要网络。

```powershell
npm ci
npm run dev
```

打开终端显示的本地地址，默认端口为8080。

源码检查使用 npm run check、npm test。构建网页版本使用 npm run build，重新生成Windows运行版使用 npm run package:desktop，输出目录为 release/雨落校园-V4.3-win-x64。

核心算法、游戏规则及开源素材授权记录位于源码包的 docs 目录，素材许可证随资源保留。
