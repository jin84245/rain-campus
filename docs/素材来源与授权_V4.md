| 资源 | 作者/来源 | 许可证 | 最终文件 | 使用位置 |
|---|---|---|---|---|
| Pulse Everyday Streets 16×16 | Pulse Games — https://edfaygo.itch.io/pulse-everyday-streets-1616 | CC0 1.0 Universal | `public/assets/campus/v4/terrain/*`、`roads/*`、`props/*`（花坛除外） | 地面、道路、行人铺装、树木、灯、椅子、排水盖 |

## 精确的五栋建筑拼装矩阵

全部编号均对应 `Kenney RPG Urban Pack/Tiles/tile_XXXX.png`，每格16×16，矩阵按行从左到右，从上到下：

| 建筑 | 第1行 | 第2行 | 第3行 |
|---|---|---|---|
| 图书馆 | 81,82,85 | 124,125,130 | 362,282,364 |
| 教学楼 | 135,136,137 | 124,128,130 | 363,365,364 |
| 食堂 | 43,44,45 | 70,71,72 | 205,282,211 |
| 超市 | 328,329,330 | 205,206,211 | 281,282,283 |
| 宿舍 | 108,109,113 | 178,179,184 | 362,363,364 |

`campus/brick/blue` 三种外观均无数值差异。

- `*-3.png`：由上表精确3×3 Kenney图块组合，原生48×48。
- `*-2.png`：由上表四角图块与项目自绘补线/门窗组成，原生32×32，并非48px缩小。
- `*-1.png`：项目自绘16×16小建筑，颜色与各建筑对应，仍保持逻辑锚点；地图空间不足时使用小规格楼体，通过牌匾和UI建筑列表显示完整名称。
- 游戏以原生PNG**统一2倍放大**至32／64／96像素；摄像机的整体适配缩放仍可能是非整数，这与源贴图缩放分开处理。
覆盖层见 `scripts/v4-overlays/`，构建脚本 `scripts/rebuild-v4-assets.py`（需本地安装 Pillow，最终游戏运行不需要 Python）。它能从两份原始用户提供的 ZIP 重新生成113张**逐文件哈希相同（经本环境校验）**的 PNG；使用方式：

```powershell
python scripts/rebuild-v4-assets.py --pulse artifacts/source-downloads/pulse-everyday-streets-16x16.zip --urban artifacts/source-downloads/kenney-rpg-urban-pack.zip --out public/assets/campus/v4
python scripts/check-v4-assets.py
```

默认 PNG 已随补丁交付，不需要再下载或运行重建脚本。`asset-manifest.json` 列出每张PNG的准确来源、目标路径及 SHA256。`LICENSE-Pulse-CC0.txt` 和 `LICENSE-Kenney-RPG-Urban-CC0.txt` 是原始许可文本随包保留。

## 代码许可与注意事项

- Phaser、Electron 及构建测试工具依然沿用现有依赖；本补丁**未复制第三方完整游戏的源码**。
- 视觉变更只是对 Phaser 4 渲染与原生 CSS 的项目代码改写，不需要在游戏中引入额外 npm 依赖。
- `artifacts/previews/map-v4.1-static-NOT-RUNTIME.jpg` 是使用相同图片与固定地图数据合成的**静态预览**，不能冒充在浏览器中实测通过的运行截图。
- 最终便携版和源代码提交应包含上述两份许可证，避免仅在开发机文件夹保存版权说明。

## V4.1 可移动素材清单说明

`asset-manifest.json` 使用 `public/assets/campus/v4/...` **项目相对路径**，不含任何 `/mnt/data` 或 Windows 绝对路径。`scripts/rebuild-v4-assets.py --out <任意临时目录>` 生成的清单内容与工程目录下完全相同，素材仍会写在指定临时目录；将其复制回游戏的 `public/assets/campus/v4` 后运行 `python scripts/check-v4-assets.py` 校验。

本环境已验证113张PNG、原生分辨率及SHA256。许可原文以随包文件为准。
